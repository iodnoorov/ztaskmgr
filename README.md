# ztaskmgr

Терминальный менеджер задач: четыре списка на одном экране (2×2), как тетрадный лист,
поделённый на четыре части — **Работа**, **Дом**, **Личное**, **Прочее**.

Сроков и приоритетов нет: приоритет — это позиция задачи в списке.
Выполненные задачи остаются в списке зачёркнутыми.

## Сборка и запуск

```sh
cargo build --release
./target/release/ztaskmgr            # ~/.local/share/ztaskmgr/tasks.md
./target/release/ztaskmgr todo.md    # свой файл
```

## Клавиши

| Клавиша | Действие |
|---|---|
| `1`–`4`, `Tab` / `Shift+Tab` | выбор списка |
| `j`/`k`, `↓`/`↑` | движение по списку |
| `g`/`G`, `Home`/`End` | в начало / в конец |
| `Shift+↑`/`Shift+↓` | сдвинуть задачу выше / ниже |
| `m` + `1`–`4` | перенести задачу в другой список |
| `a` | добавить задачу в конец списка |
| `e`, `Enter` | редактировать |
| `Space`, `x` | выполнено / не выполнено |
| `d`, `Delete` | удалить (с подтверждением) |
| `?`, `F1` | горячие клавиши |
| `o` | о программе |
| `q`, `Ctrl+C` | выход |

В поле ввода: `Enter` — сохранить, `Esc` — отмена, `Ctrl+W` — удалить слово,
`Ctrl+A`/`Ctrl+E` — в начало/конец строки.

Горячие клавиши работают по физической клавише — одинаково в любой раскладке и с Caps Lock
(в терминалах с kitty keyboard protocol: kitty, foot, WezTerm, Ghostty, Alacritty, Konsole;
в остальных русская раскладка переводится таблицей).

Изменения сохраняются в файл сразу.

## Формат файла

Обычный Markdown, его можно править руками:

```markdown
## Работа
- [ ] Написать отчёт
- [x] Созвон с командой

## Дом
- [ ] Починить кран

## Личное

## Прочее
```

Файл перезаписывается целиком, поэтому строки другого вида (не заголовок `## …` из четырёх
категорий и не задача `- [ ]`/`- [x]`) считаются ошибкой: программа не запустится и укажет
номер строки, вместо того чтобы молча потерять их при сохранении.
