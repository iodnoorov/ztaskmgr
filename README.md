# ztaskmgr

Терминальная записная книжка дел. Каждая страница — дата, на странице все списки дел на одном
экране сеткой. Сначала их четыре — **Работа**, **Дом**, **Личное**, **Прочее**; их можно
переименовать, удалить и добавить свои, до 25. Страницы можно листать, смотреть
и править прошлые, заполнять будущие.

Сроков и приоритетов нет: приоритет — это позиция задачи в списке.
Выполненные задачи остаются в списке зачёркнутыми и уходят в его конец; снятая отметка
возвращает задачу в конец невыполненных. Задачу, которую делать уже не нужно, можно
отменить (`c`): она тоже уходит вниз зачёркнутой, с `✗`, не переносится на следующий день
и не считается в счётчике списка.

## Перенос дел

- **Автоматически.** В начале дня (при запуске или в полночь, если программа открыта)
  невыполненные задачи с последней заполненной страницы переезжают на сегодняшнюю,
  в конец тех же списков.
- **Вручную** — `>`: задача уезжает на любую другую дату (по умолчанию — на завтра).

На старой странице перенесённая задача остаётся как запись: `[>] Позвонить → 30 октября`.

## Списки

`L` открывает окно списков: `a` — добавить, `e` — переименовать, `d` — удалить,
`Shift+↑`/`Shift+↓` — порядок на экране, `p` — скрыть от ИИ.

Сетка растёт вместе с числом списков: 2×2, 3×2, 3×3, 4×3, 4×4, 5×4, 5×5. Цифры `1`–`9`
выбирают первые девять списков, к остальным — `Tab` или соседний список: `h`/`l` (`←`/`→`)
и `Ctrl+↑`/`Ctrl+↓`. `m` переносит задачу в список, выбранный в окне.

Удалённый список, в котором были задачи, уходит в архив. Его задачи с сегодняшней страницы
и дальше переезжают в список, который вы выберете, а на прошлых страницах он остаётся как был
(с пометкой «архив»). Вернуть его на экран — `r` в окне списков. Список, в котором задач
не было никогда, удаляется совсем.

## Записи по задаче

`n` открывает записи выделенной задачи: подзадачи-чекбоксы и заметки, которые сами получают
дату и время. Заметка может быть в несколько строк: в её поле `Enter` — новая строка,
`Ctrl+S` — сохранить, `Esc` — закрыть. Пока заметку пишут, она сама сохраняется раз
в 10 секунд; `Esc` закрывает поле, не трогая уже сохранённое, а если есть несохранённые
изменения — сначала спрашивает. При выходе (`Ctrl+C`) начатая заметка тоже сохраняется. Длинный текст удобнее писать во внешнем редакторе — `E` открывает файл записей
в `$VISUAL` / `$EDITOR` (иначе `vi`). У задачи с записями на странице значок `✎`,
с подзадачами — `✎ 1/3`. Задача выполненной сама не становится: её отмечаете вы.

**Превью.** На широком экране (от 120 колонок) справа от списков — панель с выделенной
задачей целиком: состояние, история по страницам, через которые она переезжала, подзадачи
и заметки. Тап по панели открывает записи, `J`/`K` или колесо мыши — прокрутка. `v` прячет
и показывает панель.

Записи едут вместе с задачей при переносе. Удалённое из записей не пропадает: удалённая заметка
или подзадача, а также записи удалённой задачи (если других её копий в книжке нет) дописываются
в `DELETED_NOTES.md`.

## Синхронизация и телефон

Книжка — обычные файлы, поэтому синхронизирует её [Syncthing](https://syncthing.net):
напрямую между компьютером и телефоном, без облака. Достаточно сделать каталог книжки общей
папкой Syncthing на обоих устройствах.

- Временные файлы записи (`*.tmp`) Syncthing не возит: программа сама кладёт в книжку
  `.stignore`.
- Если одну страницу (или записи задачи) успели поменять на двух устройствах сразу, Syncthing
  оставит рядом копию `….sync-conflict-….md`. Программа сливает её сама — при запуске и раз
  в пару секунд, пока открыта: задачи объединяются (одна и та же не дублируется — у каждой
  задачи постоянный id), у одной задачи берётся «дальнейшее» состояние (выполнена → перенесена →
  открыта), записи объединяются по пунктам. Копия после слияния удаляется.
- Открытая программа подхватывает файлы, пришедшие с другого устройства, сама.

### Android (Termux)

```sh
pkg install rust git
git clone https://github.com/iodnoorov/ztaskmgr && cd ztaskmgr
cargo build --release && cp target/release/ztaskmgr $PREFIX/bin/
termux-setup-storage
# папка книжки — общая папка Syncthing-Fork на телефоне:
echo 'export ZTASKMGR_DIR=~/storage/shared/Syncthing/ztaskmgr' >> ~/.bashrc
```

На узком экране (меньше 80 колонок) — вкладки и один список на экран. Управлять можно
касаниями: тап по задаче — выделить, по выделенной — её записи, по `[ ]` — отметить, по вкладке —
список, по ◀ ▶ в шапке — день (по дате — сегодня), по подсказке внизу — как нажать её клавишу;
свайп вверх-вниз — по списку. Клавиши работают как обычно, в том числе в русской раскладке.

Пока открыто поле ввода, программа не перехватывает касания — тап по экрану вызывает
клавиатуру, как обычно в Termux. Чтобы кнопка клавиатуры была под рукой всегда, добавьте её
в строку доп. клавиш (`~/.termux/termux.properties`, затем `termux-reload-settings`):

```
extra-keys = [['ESC','TAB','CTRL','ALT','LEFT','DOWN','UP','RIGHT','KEYBOARD']]
```

Каталог книжки по умолчанию можно задать переменной `ZTASKMGR_DIR`.

## ИИ-агенты (MCP)

`ztaskmgr mcp` — MCP-сервер по stdio: книжка как инструменты для Claude Code, opencode,
локальных моделей и любых других MCP-клиентов. Агент может посмотреть страницы за период
(«что у меня по работе на этой неделе»), найти задачу, прочитать её историю и записи,
добавить задачу или заметку, отметить, перенести, удалить.

```sh
cargo install --path .
claude mcp add ztaskmgr -- ztaskmgr mcp            # Claude Code
claude mcp add ztaskmgr -- ztaskmgr mcp ~/notes    # своя книжка
```

**Скрытое от ИИ.** `P` скрывает текущий список целиком (🔒 у названия, хранится
в `LISTS.md`), `p` — отдельную задачу (🔒 у задачи, `<!-- private -->` в файле). Скрытого
агент не видит вовсе: ни в выдаче, ни в поиске, ни по ссылке, — и не может писать в скрытые
списки. Задача из скрытого списка, перенесённая в открытый, остаётся скрытой, пока вы её
не откроете; задача, перенесённая в скрытый список, скрыта вместе со всеми записями.

Удалённое агентом, как и удалённое в программе, не пропадает: записи уходят в `DELETED_NOTES.md`.
Если программа открыта, правки агента появляются в ней сразу («Обновлено снаружи»).

## Сборка и запуск

```sh
cargo build --release
./target/release/ztaskmgr             # книжка в ~/.local/share/ztaskmgr
./target/release/ztaskmgr ~/notes     # свой каталог
```

## Клавиши

| Клавиша | Действие |
|---|---|
| `1`–`9`, `Tab` / `Shift+Tab` | выбор списка |
| `h`/`l`, `←`/`→`, `Ctrl+↑`/`Ctrl+↓` | соседний список в сетке |
| `L` | окно списков |
| `j`/`k`, `↓`/`↑` | движение по списку |
| `g`/`G`, `Home`/`End` | в начало / в конец |
| `[`/`]`, `PgUp`/`PgDn` | предыдущий / следующий день |
| `t` | сегодня |
| `D` | перейти к дате |
| `a` | добавить задачу в конец списка |
| `e`, `Enter` | редактировать |
| `Space`, `x` | выполнено / не выполнено |
| `c` | отменить / вернуть в открытые |
| `Shift+↑`/`Shift+↓` | сдвинуть задачу выше / ниже |
| `m` | перенести задачу в другой список |
| `>` | перенести задачу на другую дату |
| `d`, `Delete` | удалить (с подтверждением) |
| `n` | записи задачи |
| `v` | превью задачи справа / убрать |
| `J`/`K` | прокрутка превью |
| `S` | настройки |
| `p` | скрыть задачу от ИИ / открыть |
| `P` | скрыть список от ИИ / открыть |
| `?`, `F1` | горячие клавиши |
| `o` | о программе |
| `q`, `Ctrl+C` | выход |

В поле ввода: `Enter` — сохранить, `Esc` — отмена, `Ctrl+W` — удалить слово,
`Ctrl+A`/`Ctrl+E` — в начало/конец строки. Дата вводится как `2026-10-27`, `27.10.2026`,
`27.10` или `+1` / `-3` (дни от открытой страницы).

В окне записей: `a` — заметка, `s` — подзадача, `e`/`Enter` — править пункт, `Space`/`x` —
подзадача выполнена, `Shift+↑`/`Shift+↓` — сдвиг, `d` — удалить пункт, `E` — редактор,
`Esc`/`q`/`n` — закрыть, `?` — справка.

Горячие клавиши работают по физической клавише — одинаково в любой раскладке и с Caps Lock
(в терминалах с kitty keyboard protocol: kitty, foot, WezTerm, Ghostty, Alacritty, Konsole;
в остальных русская раскладка переводится таблицей). Дни недели и месяцы — в системной локали.

Изменения сохраняются сразу.

## Настройки

`S` открывает настройки этого устройства. Они лежат в `~/.config/ztaskmgr/config` и
не синхронизируются вместе с книжкой: на телефоне и компьютере они свои. Файл можно
править руками — строки `ключ = значение`:

```
preview = off    # панель превью (по умолчанию on)
```

## Формат файлов

Страница — файл `ГГГГ-ММ-ДД.md` в каталоге книжки. Пустая страница — это отсутствие файла:
если удалить с неё все задачи, файл удаляется. Обычный Markdown, его можно править руками:

```markdown
## Работа <!-- list:work -->
- [ ] Написать отчёт
- [x] Созвон с командой

## Дом <!-- list:home -->
- [>] Позвонить мастеру → 2026-10-30
- [-] Купить шторы
```

После названия списка — его постоянный id: название можно менять, страницы при этом
не переписываются. Пустых списков в файле нет. Сами списки, их порядок и названия лежат
в `LISTS.md`:

```markdown
- Работа <!-- list:work -->
- Личное <!-- list:personal hidden -->
- Ремонт <!-- list:k3x9ab archived -->
```

Руками можно писать и заголовок без id — `## Дом`: список найдётся по названию.

Задача с записями помечена в конце строки: `- [ ] Починить кран <!-- id:k3x9ab -->`, а сами
записи лежат в `notes/k3x9ab.md`:

```markdown
- [ ] купить прокладку
- [x] перекрыть воду
- 26.10.2026 19:40 мастер сказал:
  менять смеситель целиком

  позвонить в пятницу
```

Строки заметки после первой — с отступом в два пробела, как продолжение пункта в Markdown.

Файл страницы перезаписывается целиком, поэтому строки другого вида (не заголовок `## …` известного
списка и не задача `- [ ]`, `- [x]`, `- [-]`, `- [>] … → дата`) считаются ошибкой: страница
откроется только для просмотра и программа укажет номер строки, вместо того чтобы молча
потерять их при сохранении.
