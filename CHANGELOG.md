# Изменения

Версии — по [semver](https://semver.org/lang/ru/): минорная — новая возможность, патч —
исправление. **Формат книжки** — номер в `LISTS.md` (`<!-- ztaskmgr format N -->`); книжку более
нового формата программа читает, но реестр списков не перезаписывает. Если книжкой пользуются
несколько устройств, обновлять программу нужно на всех сразу.

## 0.10.0 — 30.10.2026 · формат 3

- **Свой центр сертификации без установки в систему:** `webdav_ca` — PEM-файл, которому WebDAV
  доверяет вдобавок к встроенным и системным сертификатам («WebDAV: свой сертификат»
  в настройках).
- Ошибка WebDAV в строке состояния больше не начинается с «WebDAV: WebDAV:».
- Удалён отдельный Android/Slint-клиент и его зависимости; остаются TUI, MCP и общее ядро.
  Терминальная версия в Termux по-прежнему поддерживается.
- Локальные изменения книжки согласуются межпроцессной блокировкой; устаревший снимок
  возвращает конфликт, а открытый черновик сливается с актуальной страницей под блокировкой.
- Файлы и настройки записываются через уникальные временные файлы. Ошибка сохранения
  настройки не оставляет новое значение в памяти как успешно применённое.
- Ошибка чтения или разбора внешней страницы больше не приводит к её перезаписи; локальный
  черновик сохраняется. Надгробия остаются и после удаления последней задачи.
- Автоматический и ручной перенос повторяемы после частичного сбоя: не создают дубли
  и не переоткрывают уже завершённую копию на целевой странице.
- WebDAV больше не выполняет безусловную перезапись/удаление после конфликта ETag.
  Для изменения существующих файлов и смены фразы нужен сильный ETag; чтение и создание
  отсутствующих файлов работают и без него. Имена вроде `127.example.org` не считаются loopback.
- Настройки TUI прокручиваются вслед за выделением; нижние пункты доступны мышью и на
  коротком терминале.
- Календарная арифметика проверяет переполнение и диапазон лет 1–9999; некорректная дата
  возвращает ошибку, не завершает MCP-процесс.
- Новые id задач и списков — 16 случайных hex-символов с проверкой занятых идентичностей;
  прежние id совместимы, дубли задач внутри страницы диагностируются.

## 0.9.0 — 28.10.2026 · формат 3

- Ядро вынесено в крейт `ztaskmgr-core` (`core/`): книжка, формат, слияние, WebDAV,
  шифрование. Программа для терминала не изменилась.

## 0.8.0 — 28.10.2026 · формат 3

- **Шифрование книжки на сервере.** С фразой шифрования (настройки `S` или
  `webdav_passphrase` / `webdav_passphrase_command`) файлы уходят на WebDAV-сервер
  зашифрованными: XChaCha20-Poly1305, ключ книжки в `.ztaskmgr-key` зашифрован ключом
  из фразы (Argon2id). На устройствах книжка — по-прежнему Markdown. Открытая книжка
  на сервере при первой синхронизации с фразой перешифровывается целиком.
- **Смена фразы шифрования** в настройках: перешифровывается только ключ книжки на сервере,
  файлы не трогаются.

> Версии до 0.8.0 зашифрованные файлы прочитать не могут: синхронизация в них покажет
> «не текст». Обновите программу на всех устройствах, прежде чем включать шифрование.

## 0.7.0 — 28.10.2026 · формат 3

- **WebDAV: системные сертификаты.** Сертификат сервера проверяется не только по встроенным
  корневым сертификатам, но и по системным (`/etc/ssl/certs`, `SSL_CERT_FILE`): подходят свои
  центры сертификации и самоподписанные сертификаты, добавленные в систему.

## 0.6.0 — 28.10.2026 · формат 3

- **Синхронизация — только WebDAV.** Syncthing убран: нет `.stignore` и слияния копий
  `….sync-conflict-…`. Дела, пришедшие с сервера, переезжают на сегодня, как при запуске.
- **Слияние по времени правки.** У задачи и у списка — время последней правки (`t:` в служебном
  комментарии): побеждает более поздняя правка, поэтому снятая отметка, «открыть для ИИ»
  и «вернуть из архива» больше не откатываются. Удалённые задачи и списки оставляют надгробия
  (`<!-- deleted: … -->`, `<!-- removed: … -->`) и не воскресают при слиянии.
- Незнакомые служебные пометки `ключ:значение` сохраняются как есть — задел на будущие форматы.
- **Скрытое от ИИ:** задача, переложенная в скрытый список, больше не видна агенту через старые
  копии `[>]` и историю (найдено код-ревью).
- **WebDAV:**
  - испорченный файл не останавливает синхронизацию остальных;
  - команда пароля запускается один раз, когда терминал свободен;
  - пароль по `http://` не на этот же компьютер — только с `webdav_insecure = on`;
  - поддержка слабых ETag и ETag с числовыми XML-сущностями.
- Правка в программе не затирает то, что синхронизация или агент записали в тот же файл
  мгновением раньше: изменения сливаются.
- Испорченный `LISTS.md` больше не делает книжку непригодной: страницы читаются, реестр
  не перезаписывается, пока файл не исправят.
- Перевод `AI_HIDDEN.md` в `LISTS.md` — явная миграция при запуске.
- Внутреннее: слой хранения `Store`, кэш разобранных страниц, слияние — чистые функции,
  `ListId` без глобальной блокировки, новые id из `/dev/urandom`.

> **Важно.** Версии до 0.6.0 не понимают пометку `t:` в задачах: такая программа покажет её
> как часть текста задачи и потеряет id при сохранении. Обновите программу на всех
> устройствах, прежде чем открывать книжку.
