# ztaskmgr

Терминальная записная книжка дел. Каждая страница — дата, на странице четыре списка на одном
экране (2×2): **Работа**, **Дом**, **Личное**, **Прочее**. Страницы можно листать, смотреть
и править прошлые, заполнять будущие.

Сроков и приоритетов нет: приоритет — это позиция задачи в списке.
Выполненные задачи остаются в списке зачёркнутыми.

## Перенос дел

- **Автоматически.** В начале дня (при запуске или в полночь, если программа открыта)
  невыполненные задачи с последней заполненной страницы переезжают на сегодняшнюю,
  в конец тех же списков.
- **Вручную** — `>`: задача уезжает на любую другую дату (по умолчанию — на завтра).

На старой странице перенесённая задача остаётся как запись: `[>] Позвонить → 30 октября`.

## Записи по задаче

`n` открывает записи выделенной задачи: подзадачи-чекбоксы и заметки, которые сами получают
дату и время. Заметка может быть в несколько строк: в её поле `Enter` — новая строка,
`Ctrl+S` — сохранить, `Esc` — закрыть. Пока заметку пишут, она сама сохраняется раз
в 10 секунд; `Esc` закрывает поле, не трогая уже сохранённое, а если есть несохранённые
изменения — сначала спрашивает. При выходе (`Ctrl+C`) начатая заметка тоже сохраняется. Длинный текст удобнее писать во внешнем редакторе — `E` открывает файл записей
в `$VISUAL` / `$EDITOR` (иначе `vi`). У задачи с записями на странице значок `✎`,
с подзадачами — `✎ 1/3`. Задача выполненной сама не становится: её отмечаете вы.

Записи едут вместе с задачей при переносе. Если удалить задачу, а других её копий в книжке нет,
записи не пропадают — они дописываются в `DELETED_NOTES.md`.

## Сборка и запуск

```sh
cargo build --release
./target/release/ztaskmgr             # книжка в ~/.local/share/ztaskmgr
./target/release/ztaskmgr ~/notes     # свой каталог
```

## Клавиши

| Клавиша | Действие |
|---|---|
| `1`–`4`, `Tab` / `Shift+Tab` | выбор списка |
| `j`/`k`, `↓`/`↑` | движение по списку |
| `g`/`G`, `Home`/`End` | в начало / в конец |
| `[`/`]`, `PgUp`/`PgDn` | предыдущий / следующий день |
| `t` | сегодня |
| `D` | перейти к дате |
| `a` | добавить задачу в конец списка |
| `e`, `Enter` | редактировать |
| `Space`, `x` | выполнено / не выполнено |
| `Shift+↑`/`Shift+↓` | сдвинуть задачу выше / ниже |
| `m` + `1`–`4` | перенести задачу в другой список |
| `>` | перенести задачу на другую дату |
| `d`, `Delete` | удалить (с подтверждением) |
| `n` | записи задачи |
| `?`, `F1` | горячие клавиши |
| `o` | о программе |
| `q`, `Ctrl+C` | выход |

В поле ввода: `Enter` — сохранить, `Esc` — отмена, `Ctrl+W` — удалить слово,
`Ctrl+A`/`Ctrl+E` — в начало/конец строки. Дата вводится как `2026-10-27`, `27.10.2026`,
`27.10` или `+1` / `-3` (дни от открытой страницы).

В окне записей: `a` — заметка, `s` — подзадача, `e`/`Enter` — править пункт, `Space`/`x` —
подзадача выполнена, `Shift+↑`/`Shift+↓` — сдвиг, `d` — удалить пункт, `E` — редактор,
`Esc`/`q`/`n` — закрыть, `?` — справка.

Горячие клавиши работают по физической клавише — одинаково в любой раскладке и с Caps Lock
(в терминалах с kitty keyboard protocol: kitty, foot, WezTerm, Ghostty, Alacritty, Konsole;
в остальных русская раскладка переводится таблицей). Дни недели и месяцы — в системной локали.

Изменения сохраняются сразу.

## Формат файлов

Страница — файл `ГГГГ-ММ-ДД.md` в каталоге книжки. Пустая страница — это отсутствие файла:
если удалить с неё все задачи, файл удаляется. Обычный Markdown, его можно править руками:

```markdown
## Работа
- [ ] Написать отчёт
- [x] Созвон с командой

## Дом
- [>] Позвонить мастеру → 2026-10-30

## Личное

## Прочее
```

Задача с записями помечена в конце строки: `- [ ] Починить кран <!-- id:k3x9ab -->`, а сами
записи лежат в `notes/k3x9ab.md`:

```markdown
- [ ] купить прокладку
- [x] перекрыть воду
- 2026-10-26 19:40 мастер сказал:
  менять смеситель целиком

  позвонить в пятницу
```

Строки заметки после первой — с отступом в два пробела, как продолжение пункта в Markdown.

Файл страницы перезаписывается целиком, поэтому строки другого вида (не заголовок `## …` из четырёх
категорий и не задача `- [ ]`, `- [x]`, `- [>] … → дата`) считаются ошибкой: страница
откроется только для просмотра и программа укажет номер строки, вместо того чтобы молча
потерять их при сохранении.
